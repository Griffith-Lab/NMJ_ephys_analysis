# NMJ_ephys_analysis
Matlab code used to analyze intracellular NMJ recordings

mEJP_analysis.m takes .mat files from Chart software and displays the recording. After the user selects which section of 
the recording to be analyzed, the mini frequency, amplitude, and average membrane potential will be calculated. User can
change the "n" to >1 to run a batch of files.
